# WinTools 轻量级 Windows 工具箱

一个可插拔架构的 Windows 小工具集合。已完成**迭代 0~18 + UI 改版**：宿主外壳 + 工具自动发现机制跑通，**阶段二锁定的 7 个 MVP 工具全部实现**（JSON 格式化、Base64 编解码、随机密码生成、哈希校验、批量重命名、系统信息总览、端口占用查询），另有验证用示例工具，以及**网络信息查询、URL 编解码、时间戳转换、环境变量查看、二维码生成、文本对比、文件编码转换、图片格式转换、图片批量压缩、报名照片处理、文件夹大小分析、Ping 测试、重复文件查找、文本统计、UUID 生成、屏幕截图**这些后续工具（源码共 **24 个**，已发布 v0.17.1 安装包含 24 个）。界面按 ToolBox 四张原型图重做（v2）：工具目录首页、六分类导航、浅/暗双主题、独立搜索页、两栏工作台。

当前最新版本 **v0.17.1**，重点是把**屏幕截图**打磨成完整工具：细线标注工具栏（矩形/椭圆/箭头/画笔/马赛克/文字/内置 emoji）、就地文字输入、滚动长图拼接、桌面窗口智能识别与可调选区、全局热键与托盘常驻、截图后自动复制。详见下方「屏幕截图」段落与 [CHANGELOG.md](CHANGELOG.md)。

## 快速开始

### 环境要求
- Windows 10 及以上
- .NET 10 SDK（本项目已安装 10.0.404）

### 编译与运行

```bash
# 编译（推荐用 -m:1 避免个别环境下并行编译的文件占用问题）
dotnet build WinTools.sln -m:1

# 运行宿主程序
cd src/WinTools.Shell/bin/Debug/net10.0-windows
WinTools.Shell.exe
```

启动后首页是工具目录：顶部常用工具区，下方按六大分类展示卡片（图标/名称/快捷键/描述/星标）。左侧导航含：
- 全部工具 / 我的收藏 / 最近使用
- 分类：系统维护、文件处理、文本编码、网络工具、开发辅助、媒体办公
- 应用：设置（含主题切换说明）

工具的业务分类仍是 JSON/Base64/密码（文本工具）、哈希/重命名（文件工具）、系统信息/端口/网络信息（系统工具），只是展示层按原型六分类重新归档。

### 运行测试

建议逐个项目运行（最稳定）：

```bash
dotnet test tests/WinTools.Core.Tests/WinTools.Core.Tests.csproj
dotnet test tests/WinTools.Tools.Tests/WinTools.Tools.Tests.csproj
dotnet test tests/WinTools.DiscoveryTests/WinTools.DiscoveryTests.csproj
```

当前共 **486 个测试**：102 个核心单测 + 343 个工具逻辑单测 + 41 个发现机制集成测试，应全部通过。
（Windows 下偶发 xUnit 适配器丢失或杀软锁定 DLL 时，去掉 `--no-build` / `--no-restore` 重跑；若仍被锁，删掉对应测试项目的 `bin`/`obj` 目录再跑，详见操作手册"常见坑位"。）

├── WinTools.Tools.File/    文件与图片工具（哈希校验 / 批量重命名 / 文件编码转换 / 图片格式转换 / 图片批量压缩 / 报名照片处理 / 文件夹大小分析 / 重复文件查找 / 屏幕截图）

当前已有工具：**示例工具**（验证用）、**JSON 格式化**（迭代 1）、**Base64 编解码**、**随机密码生成**（迭代 2）、**哈希校验**（迭代 3）、**系统信息总览**、**端口占用查询**（迭代 4）、**批量重命名**（迭代 5）、**网络信息查询**（本机 IP / 网关 / DNS / MAC，逐网卡展示）、**URL 编解码**、**时间戳转换**、**环境变量查看**、**二维码生成**、**文本对比**、**文件编码转换**、**图片格式转换**、**图片批量压缩**、**文件夹大小分析**、**Ping 测试**、**重复文件查找**、**文本统计**、**UUID 生成**、**屏幕截图**（源码共 24 个；已发布 v0.17.1 含 24 个）。

> 二维码生成填补「媒体办公」分类空白：文本/链接 → PNG，用纯托管 QRCoder 本地计算，无任何网络请求，可保存 PNG 或复制图片。文本对比基于行级 LCS，绿色新增、红色删除，超 800 行自动截断。文件编码转换在 UTF-8 / GBK / GB18030 / UTF-16 间互转，二进制文件拒绝处理，结果另存不覆盖原文件。

> 三个新工具沿用既有项目：URL 编解码与时间戳转换放进 `WinTools.Tools.Text`，环境变量查看放进 `WinTools.Tools.System`，宿主零改动即可自动发现。URL 解码把 `+` 当空格、空格编码为 `%20`；时间戳自动识别秒（10 位）与毫秒（13 位）；环境变量查看全程只读当前进程环境，不修改系统配置。

端口占用查询支持批量输入：`80,443`（多端口）、`1-20`（区间）、`80,443,8000-8010`（混合），兼容中文标点；**留空或点「全部」即扫描 1-65535 全量端口**。批量查询只调用一次 `netstat -ano`，结果按端口升序展示完整占用画像：协议、本地监听地址、连接状态、远端地址、PID、进程名/路径/命令行/启动时间/所有者/内存/线程/句柄、按进程运行时长估算的占用时长，以及高危端口标记。高危规则基于端口用途与监听范围（如 6379/3389/445 对全网监听），仅作排查提示，不等同于漏洞扫描。端口较多时只展开前 100 个占用项，空闲项汇总统计。全程只读、普通权限；进程详情依赖 WMI，权限不足时逐字段降级。

> 屏幕截图支持全屏 / 区域框选 / 滚动拼接 / 延时四种模式；**滚动截图**框选区域后向下滚动页面即可把长内容自动拼成一张长图（自动识别吸顶头部、滚太快会提示；超长图在编辑窗里可用滚轮上下平移）。**区域截图会自动识别桌面上打开的窗口**（微信、浏览器、任务栏等），画成带编号的候选框：按数字键 1~9 直接选中、Tab 循环、**悬停整块提亮**、点一下就框好，不用手动拖动；框选或点选后还能**拖八个手柄调整上下左右边界、在框内拖动整体移动**，框内**单击即确认**（`Enter` / 双击也可，`Esc` 取消）；工具页还有「桌面窗口」按钮，列出所有窗口双击即按该范围预填选区，同样可调整后再确认（识别边界用 DWM 可见边框，已排除窗口阴影，不会截多）。**工具栏里也有「滚动截图」按钮**：区域 / 全屏 / 延时截完发现是长页面，点一下就能按当前区域接着往下拼，不用退出重来。框选时选区外为半透明遮罩、选区有清晰边框、八个调整手柄与实时尺寸提示。**截取后进入一张图片大小的独立编辑窗口**（不再铺满整屏）：图片贴合窗体边缘、仅一圈绿色边框，下方紧接一条白色单排图标工具栏（选中绿色高亮、整排居中）；点矩形/椭圆/箭头/画笔/马赛克/文字/表情会在按钮下方浮出白底二级面板选颜色、粗细、块大小、字号或内置矢量表情（不依赖系统 emoji 字体），马赛克面板还带「一键打码」。支持撤销/重做（Ctrl+Z / Ctrl+Y）、复制到剪贴板（Ctrl+C，可直接粘贴微信/钉钉）、另存 PNG/JPG、置顶桌面（拖动移动、滚轮缩放、右键关闭）与退出取消（Esc）。**全局快捷键默认 `Ctrl+Shift+A` 区域 / `Ctrl+Shift+F` 全屏 / `Ctrl+Shift+S` 滚动，可在工具页自定义并持久化；主窗口关闭后收进托盘后台待命（Ctrl+Shift+T 唤起），截图完成自动复制到剪贴板**。操作反馈用画布内短暂提示，热键路径用不抢焦点的浮条提示。大图等比缩放显示以适配屏幕（超长图按宽度适配、滚轮上下平移），但标注坐标与输出始终是原图像素。抓屏前自动隐藏工具窗口避免自拍，结束恢复。全程本地 GDI+ `CopyFromScreen`，无任何网络请求；抓屏坐标一律用物理像素、绝不乘 `UiTheme.S`。设计细节见操作手册"迭代 9~18 沉淀"。

> 批量重命名是唯一写操作工具：纯函数规划 → 预览 → 二次确认 → 执行时二次校验防覆盖 → 撤销栈。设计细节见操作手册"迭代 5 沉淀"。

> 网络信息查询全程只读：不访问外网、不做 DNS 反查、不需要管理员权限；读取失败的字段单独标红，不影响其他信息。

## 界面与视觉

界面按用户提供的四张 ToolBox 原型图重做（v2，工具目录式设计）：

- **首页（工具目录）**：常用工具区 + 六分类卡片网格，每张卡含彩色图标 / 名称 / 快捷键徽章 / 描述 / 收藏星标。
- **标题栏**：四点 Logo + "ToolBox 工具箱" + ⓘ + 居中搜索框（`Ctrl + K` 聚焦）+ 主题切换 / 铃铛 + 窗口按钮。
- **双主题**：浅色 / 暗色一键切换，全界面（含工具页）跟随；暗色配色对齐 `04-dark-home` 原型。
- **左侧导航**：全部工具 / 我的收藏 / 最近使用 + 六大分类（彩色圆点）+ 设置 + 常驻托盘卡，选中项蓝色激活态。
- **搜索**：独立结果页——「搜索「关键词」」+ 结果数 + 清除按钮 + 结果卡片。
- **工具页**：两栏工作台——左侧工具信息面板（图标 / 名称 / 分类 / 快捷键 / 说明）+ 右侧工具内容，另可独立窗口打开。
- **反馈**：统一 `FeedbackBar`（成功绿 / 错误红 / 警告黄 / 信息灰，图标+文字双通道），就地显示不弹窗（危险操作的二次确认除外）。
- **共享样式库**：`src/WinTools.Core/Ui/`（`UiTheme` / `CardPanel` / `FeedbackBar` / `ToolHeader` / `ToolCard` / `ToolMeta`）。放 Core 里，所有工具 DLL 与 Shell 都能复用——**新增工具照模板建项目即自动获得一致视觉，宿主零改动**。
- **高 DPI**：`app.manifest`（asInvoker 普通权限 + 长路径感知）+ `ApplicationHighDpiMode=PerMonitorV2`，字体统一用像素单位，任何 DPI 屏幕上都不模糊、不重叠。

> 详细改动与四张对照截图见 **[docs/UI改版说明.md](docs/UI改版说明.md)** 与 `docs/screenshots/`。

## 核心机制：新增工具不改宿主

1. 工具项目名必须以 `WinTools.Tools.` 开头（**命名空间建议用复数如 `.Files`，避免与 `System.IO.File` 冲突**）。
2. 工具类实现 `ITool` 并标注 `[Tool]`。
3. `Directory.Build.props` 自动把工具 DLL 复制到 Shell 输出目录。
4. Shell 运行时扫描 DLL、反射发现、自动加入导航。

详细步骤见 **[docs/新增工具操作手册.md](docs/新增工具操作手册.md)**。
