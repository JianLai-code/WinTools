## WinTools 0.6.5

Windows 桌面工具集，单个 Shell 承载 **22 个小工具**：文件哈希校验、批量重命名、文件夹大小分析、重复文件查找、图片压缩与格式转换、文件编码转换、文本对比、文本统计、时间戳转换、URL 编解码、二维码生成、UUID 生成、Ping 测试、端口占用查询等。

### 本版重点：4 个新工具 + 多轮布局/交互修复

从 0.5.7 到 0.6.5 累计新增 4 个工具（18 → 22），并根据用户截图反馈连续修复了 5 处界面与交互问题：

- **新增 Ping 测试**：1–20 次探测、丢包率与延迟统计、失败原因中文提示；探测间隔可取消，取消时保留已完成的部分结果
- **新增重复文件查找**：按大小粗筛 + SHA-256 精查，可设最小大小、可取消、无权限目录跳过；只生成报告，绝不删除文件
- **新增文本统计 / UUID 生成**：Unicode Rune 字符统计与 UTF-8 字节数；密码学安全随机 UUID，三种格式一次最多 200 个
- **布局修复**：Ping 参数行、UUID 参数行、重复文件查找参数区、图片批量压缩参数区均按实测高度垂直居中并收紧卡片高度，消除贴顶参差与大片空白

### 完整变更

- 0.6.0 新增 Ping 测试 / 重复文件查找 / 文本统计 / UUID 生成 4 个工具，靠反射自动发现，宿主 Shell 零改动
- 0.6.1 修复 Ping 参数行标签与控件垂直居中
- 0.6.2 UUID 格式按钮并入「大写」之后并整行居中
- 0.6.3 重复文件查找提示移到「选择文件夹」按钮右侧、参数行居中
- 0.6.4 修复 Ping 取消按钮"无作用"（本机 ping 过快导致按钮一闪而过）——加可取消的探测间隔，取消时保留部分结果
- 0.6.5 图片批量压缩「开始压缩」并入「清空」之后、提示文字紧跟质量行、间距统一
- 累计 279 个测试全绿（4 契约 + 236 工具 + 39 发现）

完整历史见 [CHANGELOG.md](https://github.com/JianLai-code/WinTools/blob/main/CHANGELOG.md)。
