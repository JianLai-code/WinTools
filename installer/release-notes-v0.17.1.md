## WinTools 0.17.1

Windows 桌面工具集，单个 Shell 承载 **24 个小工具**：屏幕截图（标注 / 滚动截图 / 窗口识别）、文件哈希校验、批量重命名、文件夹大小分析、重复文件查找、图片压缩与格式转换、报名照片处理、文本编码、二维码生成等。

### 截图工具重点升级（v0.11 → v0.17）

- **标注编辑器**：细线工具栏图标与悬停提示（参考微信截图），文字直接在截图上输入，内置常见矢量 emoji，置顶浮窗、倒计时、贴图一应俱全。
- **全局快捷键与托盘常驻**：默认 `Ctrl+Shift+S` 区域截图，后台常驻托盘，截图后自动复制到剪贴板。
- **滚动截图**：区域选定后向下滚动自动拼接长图，带吸顶头部识别与重叠去重；也可从标注工具栏直接发起。
- **桌面窗口智能识别**：自动列出微信、浏览器、任务栏等窗口的编号候选框，数字键 `1~9` 选中、悬停整块高亮、点击即确认；智能边界用 DWM 可见边框精确到内容，不再多截一圈阴影。
- **选区可二次调整**：八方向手柄改边界、框内拖动整体移动、单击即确认，`Esc` 取消；工具页「桌面窗口」列表选出的区域同样可调。
- **编辑窗所见即所得**：图片贴合窗体、无深色黑边，仅保留底部工具栏。

### 本版（v0.17.1）修复

- 框选后**单击即确认**，不再需要按 `Enter`
- 编辑窗去掉图片四周深色留白，**仅显示截图**
- 窗口边界改用 DWM 可见边框，实测收缩 `11/0/11/11px`，不再截进窗口外内容；带可信性校验防止远程桌面坐标异常

### 签名说明

安装包为**自签名**（发布者 `WinTools Self-Signed Development`，带 RFC3161 时间戳）。自签名不改变 SmartScreen 行为，首次运行仍需点「更多信息 → 仍要运行」。签名流程见仓库 `installer/发布说明.md` 第六节。
