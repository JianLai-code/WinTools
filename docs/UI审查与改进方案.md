# WinTools UI 审查与改进方案

> 审查日期：2026-11-19　｜　对照原型：`01-home`（浅色首页）、`04-dark-home`（暗色首页）、`02-workbench-json`（JSON 工作台）、`06-search`（搜索页）
> 本次原则：**只改视觉表现层**，不动 `ITool` 契约、不改插件发现、不重排工具内部业务逻辑。

---

## 一、逐项对比（原型 vs 当前实现）

| 维度 | 原型 | 当前实现 | 结论 |
|---|---|---|---|
| 页面结构 | 浮窗式圆角窗口 + 标题栏/导航/内容三段 + 页脚引导条 | 直角全屏窗体，三段结构在，缺浮窗质感与页脚 | 结构基本对，质感缺失 |
| 布局层级 | 页头（排序/添加工具）→ 常用工具 → 分区（查看全部） | 页头只有标题+副标题，缺操作按钮与分区链接 | 层级偏单薄 |
| 视觉一致性 | 圆角卡片 + 柔和淡边框 + 轻微阴影；统一图标语言 | **卡片为直角硬边框**，仅图标块圆角；两套图标混用 | 最突出问题 |
| 组件样式 | 标题栏搜索框带放大镜、圆角、聚焦蓝边；按钮圆角 | 搜索框为直角 `FixedSingle`，无图标；按钮为系统直角 | 明显不符 |
| 交互反馈 | hover 卡片微高亮、导航选中蓝条、搜索聚焦态 | 有 hover/选中，但无聚焦态、无圆角反馈 | 部分具备 |
| 响应式 | 固定窗口，内容区随宽重排卡片 | 有 `Resize` 重排，基本可用 | 符合 |
| 可用性 | 导航项带线性图标、分类圆点在右、结果卡片紧凑 | 导航图标为文本符号、圆点在左、搜索结果用大卡片 | 细节偏差 |

## 二、缺陷清单（按严重程度）

### P0 — 严重（决定"精致感"的核心）

1. **卡片无圆角、硬边框** — `src/WinTools.Core/Ui/ToolCard.cs:30-31`、`CardPanel.cs:19-20`
   `BorderStyle.FixedSingle` 生成 1px 直角硬框，与原型圆角柔边卡差距最大，是"丑陋"观感的首要来源。
2. **主窗口直角、无投影** — `src/WinTools.Shell/MainForm.cs:63-67`
   `FormBorderStyle.None` 未配圆角 `Region` 与 `CS_DROPSHADOW`，缺少原型"浮在画布上的窗口"质感。
3. **常用工具紧凑卡片文字溢出/裁切** — `ToolCard.cs:58-64`、`MainForm.cs:416-424`
   紧凑卡片 `name.Location=(14,52)` 与卡片高度 72 余量不足，长名称（如"批量重命名"）出现第二行被裁切、底部横线。

### P1 — 中等（明显不符，影响辨识度）

4. **标题栏搜索框缺放大镜与圆角** — `MainForm.cs:157-174`
   直角输入框、无图标、无聚焦蓝边；原型为圆角 + 放大镜 + 居中浅底。
5. **左侧导航缺线性图标、分类圆点位置错误** — `MainForm.cs:294-352`
   "全部工具"无图标；其它用 `☆ ◷ ⚙` 文本符号而非线性图标；分类彩色圆点在文字**左**，原型在**右**。
6. **页头缺"排序""+ 添加工具"操作按钮** — `MainForm.cs:393-408`
   原型页头右侧有这两个按钮，当前缺失，页面显得空。
7. **分类标题缺"查看全部 →"** — `MainForm.cs:494-509`
   原型每个分区标题右侧有链接，当前只有"N 个工具"徽章。
8. **搜索结果用大卡片而非紧凑卡片** — `MainForm.cs:567-568`
   原型结果为横向紧凑卡（图标+名称+快捷键+描述），当前调用 `MakeCard(compact:false)`。
9. **工作台工具条按钮顺序与原型相反** — `MainForm.cs:635-654`
   原型"收藏"在左、"独立窗口打开"在右；当前相反。

### P2 — 轻微（体验细节）

10. 页头标题 22px 偏大（原型约 17px），卡片内文字偏小，比例失衡 — `MainForm.cs:397`、`ToolCard.cs:125-131`。
11. 浅色主色 `#185FA5` 偏暗、边框 `#D8DCE3` 偏重，缺少原型的通透感 — `UiTheme.cs:33,43`。
12. 工作台左侧为静态"使用说明"，原型为操作参数面板。**本次不改**：该差异需重排所有工具 UI 内部控件，属结构性重构，与"不引入无关重构、不破坏功能"约束冲突，列为后续迭代候选。

## 六、验证结果

- **编译**：Release 全量生成，0 警告 0 错误。
- **测试**：81 个单元测试全部通过（Core 3 + Tools 69 + Discovery 9）。
- **截图对照**（PrintWindow 抓取，见 `.verify/v3-*.png`）：
  - 首页浅色：圆角卡片、放大镜搜索框、导航图标、页头按钮、查看全部链接齐全；常用工具竖排卡 5 个名称完整；无横向滚动条。
  - 搜索页：关键词+聚焦蓝边、结果数+清除按钮、紧凑结果卡，符合 `06-search`。
  - 工作台：顶部"★收藏"在左、"独立窗口打开"在右，顺序与 `02-workbench-json` 一致；两栏布局、圆角、对齐正常。
- **未改动但保留的边界**：暗色板配色未调整（沿用原型 04-dark-home 色值），圆角/柔边等改动通过 `UiTheme` 属性对暗色同样生效；收藏/最近仍为内存态，重启重置（既有行为，非本次范围）。

## 七、需人工确认的效果

1. 高 DPI（125%/150%/200%）下圆角与文字是否依旧清晰无重叠——本次仅在 100% 逻辑分辨率验证。
2. 真人鼠标交互：卡片 hover 描边、星标点击、搜索聚焦蓝边的实际手感。
3. 最大化窗口时圆角被正确移除（`ApplyWindowRegion` 已处理，建议实机确认无残影）。
4. 若需要完全对齐 `02-workbench-json` 的"左侧参数面板"，需单独排期做工具 UI 结构重构（P2-12）。
