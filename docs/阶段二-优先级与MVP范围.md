## 2. 排序方法

### 2.1 打分规则

对每个候选工具从两个维度打分（沿用阶段一的初评）：

- **价值**：高 / 中 / 低——对目标用户的重要程度，结合阶段一的 5 条场景判断。
- **成本**：低 / 中 / 高——实现复杂度初估。

### 2.2 排序优先级（从高到低）

1. **高价值 + 低成本**（立即做）：收益最大、风险最小，首版核心。
2. **高价值 + 中成本**（次优先）：价值足够高，值得多花一点功夫。
3. **中价值 + 低成本**（可批量补充）：边际成本低，用来凑齐体验完整性。
4. 中价值 + 中成本（二期储备）：暂缓到第二版。
5. 中价值 + 高成本（暂缓）：如重复文件查找。
6. 低价值 / 需联网 / 需管理员（排除或观察）：受阶段一决策约束，不进首版。

### 2.3 硬约束（来自阶段一决策）

- D3：需联网的工具不进首版 → 排除 N2。
- D5：需管理员权限的工具不进首版 → 排除 S3（hosts 编辑）至二期。
- 用户已确认 MVP 规模 5-7 个 → 从排序靠前的工具中截取。

## 6. 验收用例（每个 MVP 工具可验证"做完没有"）

> 用例格式：编号 / 前置条件 → 操作 → 预期结果。每条都可直接拿去手动或自动测试。

### F1 哈希校验
- **F1-AC1** 单文件：拖入 1 个文本文件 → 同时显示 MD5、SHA1、SHA256 三个值，且与系统命令 `certutil -hashfile` 结果一致。
- **F1-AC2** 多文件：一次拖入 3 个文件 → 列表逐行显示每个文件的哈希，互不串扰。
- **F1-AC3** 大文件：拖入一个 >500MB 的文件 → 显示进度且界面不假死，完成后哈希值正确。
- **F1-AC4** 异常：拖入一个被占用/无权限的文件 → 该文件行显示明确错误原因，其余文件仍正常计算，程序不崩溃。
- **F1-AC5** 复制：点击"复制"按钮 → 哈希值进入剪贴板，可直接粘贴。

### T1 JSON 格式化/校验
- **T1-AC1** 合法输入：粘贴一段合法嵌套 JSON → 输出按层级缩进的格式文本。
- **T1-AC2** 语法错误：粘贴缺少右括号的 JSON → 指出错误行号与原因，不输出半成品结果。
- **T1-AC3** 空输入：留空点击格式化 → 给出"请输入内容"提示，不报错。
- **T1-AC4** 中文内容：含中文字符的 JSON → 格式化后中文不乱码。

### S1 系统信息总览
- **S1-AC1** 核心字段：打开工具 → 一屏显示 CPU 型号、内存容量、操作系统版本、磁盘容量。
- **S1-AC2** 只读安全：以普通用户身份运行 → 能读到全部上述信息，无需管理员权限。
- **S1-AC3** 可复制：点击复制 → 全部信息以结构化文本进入剪贴板。
- **S1-AC4** 容错：模拟某项信息读取失败 → 该项显示"不可用"，其余字段正常，程序不崩溃。

### F2 批量重命名
- **F2-AC1** 序号规则：选 5 个文件，设置"前缀+起始序号1" → 依次重命名为前缀1…前缀5，扩展名保持不变。
- **F2-AC2** 冲突处理：新名与现有文件重名 → 自动加序号或明确提示，绝不静默覆盖原文件。
- **F2-AC3** 非法字符：规则含 Windows 非法字符（`\ / : * ? " < > |`）→ 自动过滤并告知用户。
- **F2-AC4** 预览：执行前显示"原名 → 新名"对照列表，用户确认后才真正改名。
- **F2-AC5** 撤销：改名完成后提供"撤销上一步" → 可恢复改名前的文件名。

### S2 端口占用查询
- **S2-AC1** 占用命中：输入一个确实被占用的端口（如 80 或 443）→ 显示占用进程名与 PID。
- **S2-AC2** 未占用：输入一个空闲端口 → 明确提示"未被占用"。
- **S2-AC3** 非法输入：输入 99999 或非数字 → 给出范围校验提示（1-65535）。
- **S2-AC4** 普通权限：以普通用户运行 → 能查出进程名或至少给出 PID，不因权限不足而崩溃。

### T2 Base64 编解码
- **T2-AC1** 编码：输入文本 → 输出正确的标准 Base64 串。
- **T2-AC2** 解码：输入合法 Base64 → 还原为原文。
- **T2-AC3** 中文往返：中文文本编码后再解码 → 内容与原文完全一致（编码/解码使用一致的字符集）。
- **T2-AC4** 非法输入：输入非 Base64 字符串解码 → 给出"无法解码"提示，不崩溃。

### T4 随机密码生成
- **T4-AC1** 默认生成：点击生成 → 得到符合默认长度与复杂度要求的密码。
- **T4-AC2** 参数可调：设置长度 16、勾选"含大小写+数字+符号" → 生成结果满足所有勾选条件。
- **T4-AC3** 随机性：连续生成 10 次 → 无重复，且字符分布符合所选字符集。
- **T4-AC4** 复制：点击复制 → 密码进入剪贴板。
