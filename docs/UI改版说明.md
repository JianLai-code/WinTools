# UI 改版说明：按 ToolBox 原型重做（v2）

> 本版按用户提供的四张 ToolBox 原型图（`01-home` / `04-dark-home` / `02-workbench-json` / `06-search`）重新设计界面。
> 这是继首轮"功能骨架 → 卡片化"之后的第二次改版，重点从"工具列表"升级为**工具目录式产品界面**。
> 截图见 `docs/screenshots/`，四张分别对应四个原型场景。

## 一、与上一版的差异

| 维度 | 上一版（v1） | 本版（v2，对齐原型） |
|---|---|---|
| 首页 | 欢迎卡片 + 左侧逐个列工具 | **工具目录**：常用工具区 + 六分类卡片网格（图标/名称/快捷键/描述/星标） |
| 导航 | 按工具 Category 逐个平铺 | 固定结构：全部工具/收藏/最近 + **六大分类**（带彩色圆点）+ 设置 + 常驻托盘卡 |
| 主题 | 仅浅色 | **浅色 / 暗色双主题**，标题栏一键切换，全界面跟随 |
| 搜索 | 只过滤左侧导航项 | **独立搜索结果页**：标题「搜索「关键词」」+ 结果数 + 清除按钮 + 结果卡片 |
| 工具页 | 上下堆叠的输入/结果卡 | **两栏工作台**：左侧工具信息面板 + 右侧工具内容 |
| 标题栏 | Logo + 搜索 + 窗口按钮 | 四点 Logo + 品牌 + ⓘ + **居中搜索** + 主题/铃铛 + 窗口按钮 |
| 收藏/最近 | 无 | 卡片星标收藏、工作台打开自动记入「最近使用」 |

## 二、实现要点（供维护者参考）

1. **主题系统（Core.Ui.UiTheme）**
   - 颜色从 `readonly Color` 字段改为**属性**，按 `CurrentTheme` 在浅/暗色板间取值；`SetTheme/ToggleTheme` 触发 `ThemeChanged` 事件。
   - 宿主订阅事件：重建自身配色 + 清空工具 UI 缓存（工具内控件按新主题重建）。
   - 暗色色板来自原型 `04-dark-home`：深蓝灰背景/卡片、浅色文字、蓝色主色与彩色圆点保留。

2. **展示元数据与业务契约解耦（Core.Ui.ToolMeta）**
   - 测试断言了工具的 `Id/Name/Category`，故**不改 ITool 契约**。
   - 新增映射表按 Id 提供：图标符号、一句话描述、快捷键徽章、原型六分类归属、配色索引、是否进常用区。
   - 未登记的工具自动用兜底值，仍可被发现、可点开——插件架构不受影响。

3. **工具卡片（Core.Ui.ToolCard）**
   - 彩色圆角图标块 + 名称 + 快捷键徽章 + 两行描述 + 收藏星标；`compact` 参数切换"常用工具小卡"与"分类大卡"。
   - 图标用纯文本符号（`{}` / `64` / `#` 等）而非特殊字体，规避不同系统缺字风险。

4. **三视图主窗口（Shell.MainForm）**
   - `ShowDirectory`（目录）/ `Search`（结果）/ `OpenTool`（工作台）三个视图切换，工具 UI 用 `_uiCache` 缓存保留输入状态。
   - Dock 布局规则踩坑：`Dock.Fill` 控件必须在控件集合索引 0（用 `SetChildIndex(x, 0)`），否则遮挡 Left/Right 控件——标题栏 Logo 消失就是这个原因。
   - 居中搜索框用 `Dock.Fill` 容器 + `Resize` 事件动态居中，窗口缩放自适应。

5. **工作台两栏**
   - 在 Shell 层加左侧信息面板 + 右侧工具 UI，**不改任何工具的 CreateUI**——插件架构、81 个测试零改动。
   - 工具内部仍是"输入卡 + 结果卡"的纵向结构（功能清晰、无重叠）；原型左栏的参数控件属工具特有，通用宿主无法预知，故左栏展示工具信息与使用说明。

## 三、验证结果

- 逐页自绘快照核对四个场景（浅色首页 / 暗色首页 / 搜索页 / JSON 工作台），均达到原型观感，文字无重叠、无裁切。
- 编译 0 警告 0 错误；**81 个测试全绿零回退**（3 + 69 + 9）。
- 安装包已用新界面重新打包：`installer-output/WinTools-0.1.0-setup.exe`（36 MB）。

## 四、已知边界

- 搜索匹配的是工具名/Id/分类/描述文本，不含工具"功能关键词"的完整语义索引；匹配数取决于描述文案。
- 主题切换会重置工具页输入状态（回首页或重建搜索），属可接受行为。
- 暗色下内容区滚动条仍是系统浅色（WinForms 原生控件限制），不影响可读性。
- 用 DrawToBitmap 自绘快照验证的是**静态布局**，标题栏搜索框的灰色占位符在快照中不渲染（实机正常显示）；真人鼠标交互仍需手动体验。
